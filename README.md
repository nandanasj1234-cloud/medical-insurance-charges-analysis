MEDICAL INSURANCE CHARGES ANLAYSIS

Project Overview

This project explores a medical insurance dataset to understand the factors associated with insurance charges.It focuses on data cleaning,preprocessing,correlation analysis,outlier detection,and data visualization using Python.

Objectives

  *Inspect and clean the dataset.
  *Check for missing values and duplicate records.
  *Analyze correlations.
  *Detect outliers.
  *Explore the distribution of insurance charges.
  *Visualize patterns and relationships using Seaborn and Matplotlib.

Dataset Information

  *Rows: 1338
  *Columns: 7
  *Target feauture: charges
  *Input features: age,sex,bmi,children,smoker,region,region

Tools and Libraries

  *Python
  *Pandas 
  *Numpy 
  *Matplotlib
  *Seaborn

Workflow

  1.Dataset inspection and Understanding
  2.Missing value anlaysis
  3.Duplicate detection and handling
  4.Correlation analysis
  5.Outlier detection 
  6.Target feauture didtribution analysis
  7.Data visualization using Matplotlib and Seaborn

Key Focus

  The analysis explores teh distribution of medical insurance charges and relationships between insurance charges and the available demographic and lifestyle        feautures.
